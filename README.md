
# KIWI Lawncher - Bleeding-edge sinops experiment branch!
### The world's first dedicated Swordigo launcher for Android

Raijin's Launcher is a modular, mod-friendly launcher built specifically around the Swordigo modding ecosystem.

It is designed to provide a centralized platform for installing, managing, discovering, and launching Swordigo modifications without requiring users to manually manage game files, patches, loaders, or mod dependencies.

Raijin's Launcher is **completely closed source**.

It contains **no original Swordigo assets or proprietary Swordigo source code**. The launcher itself is an independent piece of software designed to operate alongside legally obtained copies of the game and user-provided modifications.

---

## What is Raijin's Launcher?

Swordigo has a large modding community, but managing modifications has traditionally required manually moving files, maintaining different game versions, dealing with compatibility issues, and finding mods through scattered community resources.

Raijin's Launcher aims to change that.

The goal is to provide Swordigo with the kind of mod distribution and management experience that platforms such as CurseForge provide for Minecraft:

* Discover mods
* Install mods
* Manage installed mods
* Enable or disable modifications
* Handle mod dependencies
* Organize different configurations
* Launch the game through the appropriate environment
* Browse available community content
* Keep the modding experience modular and extensible

In short:

> **Raijin's Launcher is intended to be a CURSEFORGE of Swordigo.**

---

## Key Features

### Mod Browser

Discover Swordigo modifications directly through the launcher.

The planned ecosystem supports:

* Mod discovery
* Mod descriptions
* Version information
* Authors
* Compatibility information
* Dependencies
* Installation
* Updates
* Removal
* Mod metadata

The objective is to make finding and installing Swordigo mods substantially easier than manually searching through community posts and downloading files individually.

### Mod Management

Installed modifications can be managed independently.

Users can organize their setup without manually editing the game's installation directory for every change.

The launcher is designed around the idea that a user's mod configuration should be reproducible, manageable, and easy to change.

### Modular Architecture

Raijin is built around a modular architecture rather than being a single-purpose launcher.

This makes it possible to expand the ecosystem with additional components such as:

* Mod loaders
* Mod repositories
* Compatibility layers

The architecture is intended to allow new functionality to be introduced without redesigning the entire launcher.

## No Original Swordigo Assets

Raijin's Launcher does not aim to redistribute the original Swordigo game.

The project is intentionally structured around separation between:

**Raijin's Launcher**

and

**Swordigo / user-provided game data / community modifications**

This separation is a fundamental part of the project's design.

The launcher provides the infrastructure.

The community provides the modifications.

The user provides the legally obtained game installation required to use the software.

## Compatibility

Raijin is designed with compatibility and modularity as primary considerations.

Mods may target different game versions, loaders, architectures, or runtime environments. The launcher can therefore provide metadata and compatibility information to help users understand whether a particular modification is appropriate for their setup.

The exact capabilities depend on the mod, loader, and supported Swordigo environment.
